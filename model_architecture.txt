Model Architecture Overview

This document summarizes the model architectures of the three tasks in this directory, based on the final training scripts:

- task1_output/train_crc_msi_fixed.py
- task2_output/train_nsclc_v3_3.py
- task3_output/train_im_detection_v3.py

================================================================================
1. Task 1 — CRC-MSI Classification
================================================================================

Objective
Classify colorectal cancer pathology slides into two categories: MSIH (microsatellite instability-high) and NonMSIH.

Data
- Source: TCGA (CRC-MSI)
- Input: 256 x 256 RGB pathology images (resized to 256 x 256)
- Sample size: approximately 15,002 image tiles

Network Architecture

  Backbone: ResNet-50 (ImageNet pretrained weights)
    Input image (3, 256, 256)
      -> ResNet-50 convolutional backbone (original fc layer removed)
      -> global average pooled feature of 2048 dimensions

  Classification head (replaces the original fc):
    nn.Sequential(
      nn.Linear(2048, 512),
      nn.ReLU(),
      nn.Dropout(0.5),
      nn.Linear(512, 2),
    )

  Output: 2 logits (NonMSIH = 0, MSIH = 1), followed by Softmax for probabilities.

Training Configuration
- Loss function: CrossEntropyLoss
- Optimizer: Adam (lr = 1e-4)
- Learning rate scheduler: ReduceLROnPlateau (mode = 'min', factor = 0.5, patience = 3)
- Batch size: 32
- Maximum epochs: 20; early stopping patience = 5 (monitoring validation accuracy)
- Data augmentation (training set): RandomHorizontalFlip, RandomVerticalFlip,
  RandomRotation(15 degrees), ColorJitter(brightness = 0.2, contrast = 0.2)
- Normalization: ImageNet statistics
    mean = [0.485, 0.456, 0.406], std = [0.229, 0.224, 0.225]

Evaluation Metrics (test set)
- Macro-AUC: 0.6662
- Weighted-F1: 0.7652
- Macro-ACC: 0.7552

2. Task 2 — NSCLC Subtyping (LUAD vs LUSC)
================================================================================

Objective
Distinguish two subtypes of non-small cell lung cancer (LUAD vs LUSC). Trained on TCGA and independently evaluated on the Nanfang cohort.

Data and Features
- Feature extractor: Virchow2 (pathology foundation model, pre-extracted and frozen)
- Feature dimension: 2560
- Input: a bag of sampled patches per whole-slide image (bag_size = 1024)
- Feature preprocessing: per-slide z-score normalization (to reduce slide-level staining and scanner bias)
- Training augmentation: Gaussian noise added to features (std = 0.01) and instance-level dropout (inst_dropout = 0.15)

Network Architecture: MultiHeadAttentionMIL
  1) Input: features (B, N, 2560), where N is the number of patches in the bag
  2) Normalization: nn.LayerNorm(2560)
  3) Multi-head gated attention (num_heads = 4, hidden_dim = 256 per head):
       Each head contains:
         V = nn.Linear(2560, 256)   -> tanh
         U = nn.Linear(2560, 256)   -> sigmoid
         w = nn.Linear(256, 1)
       Attention scores: A = softmax( w( tanh(V(x)) * sigmoid(U(x)) ) )
       Per-head aggregation: head_out = sum( A * x )
       Attention dropout = 0.3
  4) Aggregation: mean over the 4 head outputs
  5) Classification head (MLP):
       nn.Sequential(
         nn.Linear(2560, 512), nn.ReLU(), nn.Dropout(0.5),
         nn.Linear(512, 256),  nn.ReLU(), nn.Dropout(0.3),
         nn.Linear(256, 2),
       )

  Output: 2 logits (LUSC = 0, LUAD = 1).

Training Configuration
- Loss function: CrossEntropyLoss (weights inversely proportional to class frequency)
- Optimizer: AdamW (lr = 1e-4, weight_decay = 5e-4)
- Learning rate scheduler: CosineAnnealingWarmRestarts (T_0 = 8, T_mult = 2, eta_min = 1e-6)
- Batch size: 1 (each bag is one sample), gradient accumulation steps = 4
- Maximum epochs: 30; early stopping patience = 12 (monitoring validation AUC)
- Test strategy: average predictions over 16 randomly sampled bags (test_bags = 16)

Evaluation Metrics (Nanfang test set)
- Macro-AUC: 0.8282
- Weighted-F1: 0.7097
- Macro-ACC: 0.7245

3. Task 3 — Gastric Intestinal Metaplasia (IM) Detection
================================================================================

Objective
Detect intestinal metaplasia (IM) in gastric biopsy slides, using single-center data from the PWH cohort (Peter MacCallum Cancer Centre). Train/validation/test split is 70% / 20% / 30%.

Data and Features
- Feature extractor: Virchow2 (pathology foundation model, pre-extracted and frozen)
- Feature dimension: 2560
- Input: a bag of sampled patches per whole-slide image (bag_size = 256)
- Training augmentation: Gaussian noise added to features (std = 0.01) and instance-level dropout (inst_dropout = 0.2)

Network Architecture: GatedAttentionMIL
  1) Input: features (B, N, 2560)
  2) Normalization: nn.LayerNorm(2560)
  3) Gated attention (hidden_dim = 384):
       attention_V = nn.Linear(2560, 384)   -> tanh
       attention_U = nn.Linear(2560, 384)   -> sigmoid
       attention_w = nn.Linear(384, 1)
       Attention scores: A = softmax( w( tanh(V(x)) * sigmoid(U(x)) ) )
       Attention dropout = 0.3
  4) Aggregation: bag representation = sum( A * x )
  5) Classification head (MLP):
       nn.Sequential(
         nn.Linear(2560, 512), nn.ReLU(), nn.Dropout(0.5),
         nn.Linear(512, 256),  nn.ReLU(), nn.Dropout(0.3),
         nn.Linear(256, 2),
       )

  Output: 2 logits (nonIM = 0, IM = 1).

Training Configuration
- Loss function: CrossEntropyLoss (weights inversely proportional to class frequency, addressing severe class imbalance of approximately 90/10)
- Optimizer: AdamW (lr = 1e-4, weight_decay = 5e-4)
- Learning rate scheduler: CosineAnnealingWarmRestarts (T_0 = 10, T_mult = 2, eta_min = 1e-6)
- Batch size: 4 (drop_last = True)
- Maximum epochs: 40; early stopping patience = 15 (monitoring validation AUC)

Evaluation Metrics (PWH test set)
- Macro-AUC: 0.9490
- Weighted-F1: 0.9283
- Macro-ACC: 0.9235

4. Comparison of the Three Architectures
================================================================================

  Project    Task              Backbone / Features       Aggregation                Classification Head
  ---------  ----------------  ------------------------  -------------------------  ---------------------
  Task 1     CRC-MSI           ResNet-50 (end-to-end)    Global average pooling     2048 -> 512 -> 2
  Task 2     NSCLC subtyping   Virchow2 (frozen)         4-head gated attention     2560 -> 512 -> 256 -> 2
  Task 3     GC IM detection   Virchow2 (frozen)         Single-head gated attention 2560 -> 512 -> 256 -> 2

Common points
- All tasks are binary classification (num_classes = 2).
- The classification heads all follow the structure
  "Linear -> ReLU -> Dropout(0.5) -> Linear -> (ReLU -> Dropout) -> Linear(2)".
- Task 2 and Task 3 both use Virchow2 pathology foundation model features (2560 dimensions)
  with MIL aggregation, applying an attention mechanism to weight and sum the patches within
  a bag before feeding the result into an MLP classification head.
- All tasks use Adam/AdamW optimizers, class-weighted CrossEntropyLoss, and cosine annealing
  learning rate scheduling.

Differences
- Task 1 is an end-to-end CNN (trainable ResNet-50) whose input is a single image;
  Task 2 and Task 3 use pre-extracted features with MIL, whose input is a set (bag) of patches.
- Task 2 uses a 4-head attention and averages the heads (multi-head),
  while Task 3 uses a single-head attention (gated attention).
- Task 2 additionally applies per-slide z-score normalization and multi-bag test averaging;
  Task 3 focuses mainly on weighting for severe class imbalance and feature-level noise augmentation.
