1. Task 1 —— CRC-MSI 分类（结直肠癌微卫星不稳定性分类）
================================================================================

任务目标：将结直肠癌病理切片分为 MSIH（高度微卫星不稳定）与 NonMSIH 两类。

【数据】
  - 来源：TCGA（CRC-MSI）
  - 输入：256×256 RGB 病理图像（Resize 至 256×256）
  - 样本量：约 15,002 张切片；训练/验证/测试按 70%/20%/30% 划分

【网络架构】
  Backbone：ResNet-50（ImageNet 预训练权重）
    输入图像 (3, 256, 256)
      → ResNet-50 卷积主干（移除原始 fc 层）
      → 全局平均池化后特征 2048 维

  分类头（替换原 fc）：
    nn.Sequential(
      nn.Linear(2048, 512),
      nn.ReLU(),
      nn.Dropout(0.5),
      nn.Linear(512, 2),
    )
  输出：2 个 logits（NonMSIH=0, MSIH=1），经 Softmax 得到概率

【训练配置】
  - 损失函数：CrossEntropyLoss
  - 优化器：Adam（lr=1e-4）
  - 学习率调度：ReduceLROnPlateau(mode='min', factor=0.5, patience=3)
  - 批大小：32
  - 最大轮次：20；早停 patience=5（监控验证准确率）
  - 数据增强（训练集）：RandomHorizontalFlip、RandomVerticalFlip、
    RandomRotation(15°)、ColorJitter(brightness=0.2, contrast=0.2)
  - 归一化：ImageNet 均值/标准差
      mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]

【评估指标（测试集）】
  - Macro-AUC   : 0.6662
  - Weighted-F1 : 0.7652
  - Macro-ACC   : 0.7552

2. Task 2 —— NSCLC 分型（肺腺癌 LUAD vs 肺鳞癌 LUSC）
================================================================================

任务目标：区分非小细胞肺癌的两种亚型（LUAD / LUSC），TCGA 训练、Nanfang 队列独立测试。

【数据与特征】
  - 特征提取器：Virchow2（病理基础模型，预提取、冻结）
  - 特征维度：2560
  - 输入：每张 WSI 采样 patch 组成 bag（bag_size=1024）
  - 特征预处理：逐切片 z-score 归一化（消除切片间染色/扫描仪偏差）
  - 训练数据增强：特征加高斯噪声（std=0.01）+ 实例级 dropout（inst_dropout=0.15）

【网络架构】MultiHeadAttentionMIL（多头门控注意力 MIL）
  1) 输入：features (B, N, 2560)，N 为 bag 内 patch 数
  2) 归一化：nn.LayerNorm(2560)
  3) 多头门控注意力（num_heads=4，每头 hidden_dim=256）：
       每头包含：
         V = nn.Linear(2560, 256)   → tanh
         U = nn.Linear(2560, 256)   → sigmoid
         w = nn.Linear(256, 1)
       注意力分数：A = softmax( w( tanh(V(x)) * sigmoid(U(x)) ) )
       每头聚合：head_out = sum( A * x )
       注意力 dropout = 0.3
  4) 聚合：对 4 个头输出取平均（mean）
  5) 分类头（MLP）：
       nn.Sequential(
         nn.Linear(2560, 512), nn.ReLU(), nn.Dropout(0.5),
         nn.Linear(512, 256),  nn.ReLU(), nn.Dropout(0.3),
         nn.Linear(256, 2),
       )
  输出：2 个 logits（LUSC=0, LUAD=1）

【训练配置】
  - 损失函数：CrossEntropyLoss（按类别样本数反比加权，缓解不平衡）
  - 优化器：AdamW（lr=1e-4, weight_decay=5e-4）
  - 学习率调度：CosineAnnealingWarmRestarts(T_0=8, T_mult=2, eta_min=1e-6)
  - 批大小：1（每个 bag 为一个样本），梯度累积 accum_steps=4
  - 最大轮次：30；早停 patience=12（监控验证 AUC）
  - 测试策略：随机采样 16 个 bag 分别预测后取平均（test_bags=16）

【评估指标（Nanfang 测试集）】
  - Macro-AUC   : 0.8282
  - Weighted-F1 : 0.7097
  - Macro-ACC   : 0.7245

3. Task 3 —— 肠化生检测（GC IM Detection，胃活检肠化生分类）
================================================================================

任务目标：识别胃黏膜肠化生（Intestinal Metaplasia, IM），PWH 队列（Peter MacCallum
           Cancer Centre）单中心数据，训练/验证/测试按 70%/20%/30% 划分。

【数据与特征】
  - 特征提取器：Virchow2（病理基础模型，预提取、冻结）
  - 特征维度：2560
  - 输入：每张 WSI 采样 patch 组成 bag（bag_size=256）
  - 训练数据增强：特征加高斯噪声（std=0.01）+ 实例级 dropout（inst_dropout=0.2）

【网络架构】GatedAttentionMIL（单头门控注意力 MIL）
  1) 输入：features (B, N, 2560)
  2) 归一化：nn.LayerNorm(2560)
  3) 门控注意力（hidden_dim=384）：
       attention_V = nn.Linear(2560, 384)   → tanh
       attention_U = nn.Linear(2560, 384)   → sigmoid
       attention_w = nn.Linear(384, 1)
       注意力分数：A = softmax( w( tanh(V(x)) * sigmoid(U(x)) ) )
       注意力 dropout = 0.3
  4) 聚合：bag 特征 = sum( A * x )
  5) 分类头（MLP）：
       nn.Sequential(
         nn.Linear(2560, 512), nn.ReLU(), nn.Dropout(0.5),
         nn.Linear(512, 256),  nn.ReLU(), nn.Dropout(0.3),
         nn.Linear(256, 2),
       )
  输出：2 个 logits（nonIM=0, IM=1）

【训练配置】
  - 损失函数：CrossEntropyLoss（按类别样本数反比加权，处理约 90/10 严重不平衡）
  - 优化器：AdamW（lr=1e-4, weight_decay=5e-4）
  - 学习率调度：CosineAnnealingWarmRestarts(T_0=10, T_mult=2, eta_min=1e-6)
  - 批大小：4（drop_last=True）
  - 最大轮次：40；早停 patience=15（监控验证 AUC）

【评估指标（PWH 测试集）】
  - Macro-AUC   : 0.9490
  - Weighted-F1 : 0.9283
  - Macro-ACC   : 0.9235

4. 三项目架构对比
================================================================================

  项目        任务             骨干/特征           聚合方式            分类头
  ----------  ----------------  -------------------  ------------------  ----------------
  Task 1      CRC-MSI 分类     ResNet-50(端到端)    全局平均池化       2048→512→2
  Task 2      NSCLC 分型       Virchow2(冻结特征)   4头门控注意力MIL   2560→512→256→2
  Task 3      GC IM 检测       Virchow2(冻结特征)   单头门控注意力MIL  2560→512→256→2

  共同点：
    - 均为二分类任务（num_classes=2）
    - 分类头均采用 "Linear→ReLU→Dropout(0.5)→Linear→(ReLU→Dropout)→Linear(2)" 结构
    - Task2/Task3 均使用 Virchow2 病理基础模型特征（2560 维）做 MIL 聚合，
      通过注意力机制对 bag 内 patch 加权求和，再送入 MLP 分类头。
    - 均使用 Adam/AdamW 优化器 + 类别加权 CrossEntropyLoss + 余弦退火学习率。

  差异点：
    - Task1 为端到端 CNN（ResNet-50 可训练），输入为单张图像；
      Task2/Task3 使用预提取特征 + MIL，输入为 patch 集合（bag）。
    - Task2 采用 4 头注意力并取平均（MultiHead），
      Task3 采用单头注意力（GatedAttention）。
    - Task2 额外做逐切片 z-score 归一化与多 bag 测试平均；
      Task3 主要针对严重类别不平衡做加权与特征噪声增强。
